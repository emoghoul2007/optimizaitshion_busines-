# Заявки: скрипт таблицы и расширение «Робот LP-CRM»

В репозитории нет ключей. Ключи вводятся в самой таблице (панель → «Ключи») и в расширении (вкладка «Настройки»).

## Что здесь
- `Zayavki.gs` - скрипт Google Таблицы (меню и панель «Заявки»).
- `lpcrm-robot/` - расширение Chrome для LP-CRM.
- `version.json` - номера последних версий (их показывает кнопка «Обновить скрипт таблицы»).

## Установка скрипта таблицы
1. В таблице: «Расширения» → «Apps Script» → «+» → «Скрипт», назвать «Заявки», вставить весь код из `Zayavki.gs`.
2. В начале кода вписать репозиторий: `REPO: 'логин/название'`.
3. Выбрать функцию `ustanovitMenu`, нажать «Выполнить», разрешить доступ.
4. Обновить страницу таблицы: меню «Заявки» → «Открыть панель».

Обновление: заменить весь код в файле «Заявки» новым, снова вписать `REPO`, сохранить. Ключи не пропадают.

## Установка расширения
1. Скачать `lpcrm-robot.zip` из раздела Releases, распаковать в постоянную папку.
2. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → выбрать папку.
3. В LP-CRM: значок робота → «Настройки»: адрес веб-приложения, код доступа, входной ключ API.

Обновление: заменить файлы в папке, в `chrome://extensions` нажать «обновить» у расширения.

## Как выпустить обновление (для владельца)
1. Заменить файлы в репозитории, поднять номера в `version.json`, в `SCRIPT_VERSION` (в `Zayavki.gs`) и в `manifest.json`.
2. Создать Release и приложить архив `lpcrm-robot.zip` (имя файла именно такое).
